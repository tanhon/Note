# 吾生也有涯，而知也无涯


今天是三月份最后一天，回想这一个月，感觉收获很多，也遇到很多问题。从三月初入学突发奇想开始记笔记，每天坚持背单词，学习 Java 基础，刷一道算法题，看一个小时左右的书。 中间想过考研和找工作，焦虑又迷茫，后来觉得先努力学点东西试试能不能在大三下备考前找个实习，但心里还是不够坚定，毕竟大环境还是太差了，另一方面学到了计组的内容，感受到计组的难度确实很大，估计计网也不会比这个简单，所以我畏难了，对考研也很犹豫。 再加上我注意到学校里的那几个绩点很高的人，我觉得他们考研也肯定没问题，不过他们大概率会保研。王小波说过：人的烦恼都是对自己无能的愤怒。这么看来，确实如此。马上到四月份，我在想，要不要给目前的节奏加快一些，比如每天两道算法题，做一做小项目，我承认我对未来感到有些紧张。周围也没有人和我一起，虽然孤独是人生的常态。想了这么多，还是要继续做下去。毕竟这是我最后的退路了。

延迟决策：
选择，是需要有权利的，没有权利的不能称为选择。
我现在还没有选择权。
要获得它，必须能够到那个门槛。

而我既然能做到一个月，也能做到两个月，三个月，六个月，一整年。
这个过程就是如此难熬，没有任何人带领我们，只有我们自己开路。
还记得那个作文题目——是选择先行者而是后继者
我当时的选择就是先行者，因为先行者对我来说意义是最重大的。
不管哪条路，我都相信我有能力走下去！
