# Obsidian 知识管理系统

```

│   ├── Zettelkasten模板.md
```

## 模板说明

### 1. Zettelkasten模板.md

**用途**：用于创建原子化笔记，遵循 Zettelkasten 方法论

**Frontmatter 属性**：
- `created`: ISO 格式时间（动态生成）
- `random_id`: 7位随机数字标识（动态生成）
- `时间戳UID`: 基于时间戳的唯一标识符（动态生成）
- `页面ID`: 组合格式ID（页码.随机数）

**使用方法**：在 Zettelkasten 目录中使用此模板创建新笔记，每则笔记只包含一个核心想法。

---

### 2. Create模板.md

**用途**：用于创作内容模板，如文章、博客等

**Frontmatter 属性**：
- `Status`: 创作状态（默认"创作中"）
- `platform`: 发布平台数组（默认为空）
- `tags`: 标签数组（默认为空）
- `created`: 日期格式
- `创建时间`: 双重时间标记
- `AREA`: 领域分类
- `category`: 分类
- `Update`: 日期格式

**使用方法**：在 Create 目录中使用此模板创建创作内容。

---

### 3. Diary模板.md

**用途**：用于每日复盘和笔记分析

**Frontmatter 属性**：
- `Date`: 日期格式

**结构化日记格式**：
- 日期记录
- 今日计划
- 新增笔记列表
- 当日笔记分析区域（学习收获、思考与反思、明日计划）
- 随笔

**使用方法**：在 Diary 目录中使用此模板创建每日笔记。

## BASE 数据库说明

### 1. Reference_base.base - 参考资料数据库

**目标文件夹**：Reference

**视图类型**：单一表格视图

**排序方式**：按创建时间降序排列（最新的在前）

**显示字段**：
- 文件名
- 创建时间
- 修改时间
- AI 摘要

**功能特点**：
- 用于管理参考资料文档
- 按时间倒序展示，便于快速找到最新添加的参考资料
- 包含 AI 摘要功能，方便快速了解文档内容

---

### 2. Zettelkasten_base.base - 卡片盒数据库

**目标文件夹**：Zettelkasten

**双视图设计**：
1. **表格视图**：
   - 按创建时间降序，页面 ID 升序排列
   - 显示字段：文件名、创建时间、标签、时间戳 UID
   - 适合结构化浏览和查找

2. **卡片视图**：
   - 使用随机数排序，实现随机展示效果
   - 卡片式布局，适合视觉化浏览
   - 随机排序算法基于时间戳 UID 和当前时间分钟数

**随机数公式**：
```
(( (number(this.时间戳UID) * 100011979 + 500067713) % 900066731 )
 * ( (now().minute * 800067089 + 800068411) % 800053967 )
 + 900067309) % 900066571
```

**设计理念**：
Zettelkasten 数据库的核心是促进知识的随机碰撞和意外发现，通过随机排序帮助用户打破思维定式，发现笔记之间意想不到的联系。

## 使用指南

### 1. 笔记创建流程

1. **选择模板**：使用 `/template/` 目录中的模板
2. **创建原子化笔记**：遵循 Zettelkasten 原则，每则笔记一个核心想法
3. **元数据管理**：利用 frontmatter 属性进行元数据管理
4. **内容编写**：使用 Markdown 语法，保持结构清晰
5. **建立链接**：在相关上下文中添加链接，创建知识网络

### 2. 链接笔记系统

**基本链接语法**：
- `[[笔记名称]]` - 创建内部链接
- `[[笔记|显示文本]]` - 自定义链接显示文本
- `[[笔记#标题]]` - 链接到特定标题
- `[[笔记#^块标识]]` - 链接到特定文本块

**高级链接功能**：
- `![[文件]]` - 嵌入文件内容（图片、PDF等）
- `[[^^搜索文本]]` - 搜索并链接到包含特定文本的块
- `[[##标题]]` - 搜索并链接到包含特定文本的标题

### 3. 最佳实践

1. 遵循原子化笔记原则 - 每则笔记一个想法
2. 在笔记之间建立有意义的联系
3. 维护一致的 frontmatter 结构
4. 定期审查和完善知识图谱
5. 利用各种插件提高生产力

- 文件浏览器
- 全局搜索
- 反向链接面板
- 标签面板
- 日记
- 模板
- 命令面板
- 大纲
- 字数统计
- 画布
- 属性

### 社区插件
- **templater-obsidian**: 模板功能支持动态内容生成
- **obsidian-tasks-plugin**: 任务管理
- **obsidian-excalidraw-plugin**: 图表绘制
- **obsidian-linter**: Markdown 语法检查和格式化
- **obsidian-bases**: 数据库功能（用于 BASE 文件）

### 模板引擎

所有模板都使用 **Templater** 插件，支持以下动态语法：
- `<% tp.date.now() %>` - 获取当前日期时间
- `<% tp.file.title %>` - 获取文件名
- `<% tp.random.number() %>` - 生成随机数
- `<% Math.floor(Date.now() / 1000) %>` - 生成时间戳

## 文件搜索命令

在创建文档链接前，请使用以下命令搜索确认目标文档存在：

- `fd "搜索内容"` - 使用 fd 工具搜索文件名
- `rg "搜索内容"` - 使用 ripgrep 搜索文件内容
- `fd -e md "关键词"` - 搜索特定扩展名的文件
- `rg -i "关键词" --type md` - 不区分大小写搜索 Markdown 文件
