# 示例笔记

## 1. Zettelkasten 原子笔记示例

在 `Zettelkasten/` 文件夹中创建一个名为 `知识管理的原子化原则` 的笔记：

```
---
created: 2026-02-25T10:30:45.123Z
random_id: 3827491
时间戳UID: 1708859445
页面ID: 1.42
---

# 知识管理的原子化原则

原子化笔记（Atomic Notes）是知识管理中的核心概念，指的是每则笔记只包含一个独立的、不可再分的想法或概念。

## 核心要点

1. **单一主题**：每则笔记专注于一个具体的想法
2. **自我完整**：笔记可以独立理解，不依赖上下文
3. **可链接性**：原子化使笔记更容易建立链接关系
4. **可组合性**：多个原子笔记可以组合成更复杂的知识

## 实践建议

- 避免在单个笔记中包含多个不同主题
- 使用清晰、描述性的标题
- 在笔记中添加上下文和来源
- 主动寻找与其他笔记的连接点

## 相关笔记

- [[知识网络构建方法]]
- [[链接笔记系统]]
- [[渐进式总结]]
```

## 4. 使用 BASE 数据库

### 查看参考资料

1. 打开 `BASE/Reference_base.base`
2. 在表格视图中可以看到所有 `Reference/` 文件夹中的笔记
3. 按创建时间排序，最新的在最前面
4. 可以查看每个笔记的文件名、创建时间、修改时间和 AI 摘要

### 浏览知识卡片

1. 打开 `BASE/Zettelkasten_base.base`
2. 切换到"表格视图"查看结构化的笔记列表
3. 切换到"卡片视图"体验随机排序的效果
4. 每分钟刷新一次，可以看到卡片顺序变化

## 6. 技巧提示

### 链接笔记

- 使用 `[[ ]]` 快速创建链接
- 按 `Ctrl+K` (Windows) 或 `Cmd+K` (Mac) 打开链接面板
- 使用 `[[笔记#标题]]` 链接到特定部分
- 使用 `[[笔记#^块标识]]` 链接到特定文本块

### 搜索笔记

- 使用全局搜索 (`Ctrl+Shift+F`) 搜索所有笔记
- 使用 `fd "关键词"` 搜索文件名
- 使用 `rg "关键词"` 搜索文件内容

### 使用反向链接

- 查看笔记的反向链接，发现意外的连接
- 利用未链接的提及，主动建立新的链接
- 定期审查反向链接，完善知识网络
