## 🗂️ 系统结构

```
您的知识库
│
├── 📚 收集区 (Clippings/) - 保存网页内容和摘录
│
├── 💡 原子笔记区 (Zettelkasten/) - 核心知识库
│   └── 每个笔记一个想法，通过链接建立网络
│
├── 📖 参考区 (Reference/) - 研究资料和文献
│
├── ✍️ 创作区 (Create/) - 文章、博客、项目
│
├── 📅 复盘区 (Diary/) - 每日反思和计划
│
└── 🗄️ 管理区 (BASE/) - 智能数据库
    ├── 参考资料数据库
    └── 知识卡片数据库
```

## 🎯 核心功能

### 1. 原子化笔记 📝

每则笔记只包含一个核心想法，便于链接和组合。

**使用方法**：
- 在 `Zettelkasten/` 中创建笔记
- 使用 `Zettelkasten模板`
- 保持内容聚焦单一主题

### 2. 智能模板 📄

自动填充时间和随机标识符，标准化笔记格式。

**可用模板**：
- 📌 `Zettelkasten模板` - 原子笔记
- ✍️ `Create模板` - 创作内容
- 📅 `Diary模板` - 每日复盘

### 3. 双向链接 🔗

使用 `[[ ]]` 语法链接笔记，构建知识网络。

**示例**：
```markdown
这个想法与 [[知识管理]] 密切相关。
```

### 4. 智能数据库 🗄️

使用 BASE 数据库可视化管理笔记：

- 📊 表格视图 - 结构化浏览
- 🎴 卡片视图 - 随机发现
- ⏰ 时间排序 - 查找最新内容

## 💡 使用技巧

### 1. 坚持原子化原则
每则笔记只写一个核心想法，不要贪多。

### 2. 主动建立链接
不要等待链接自然形成，主动寻找相关笔记。

### 3. 定期复习
每周回顾笔记，每月深度复习重要笔记。

### 4. 使用反向链接
经常查看反向链接，发现意外的知识连接。

### 5. 保持简洁
笔记内容保持简洁明了，重点突出。

## 🎓 常见问题

### Q: 如何创建链接？
A: 使用 `[[笔记名]]` 语法，输入 `[[` 后会自动提示。

### Q: 模板没有自动填充？
A: 确保 Templater 插件已启用并正确配置。

### Q: BASE 不显示笔记？
A: 检查笔记是否在正确的文件夹中（Zettelkasten 或 Reference）。

### Q: 如何修改模板？
A: 直接编辑 `template/` 文件夹中的对应模板文件。

### Q: 如何备份？
A: 使用 Git 或复制到云存储/外部硬盘。

**更多问题**：查看 [配置指南.md](配置指南.md) 中的常见问题部分。
