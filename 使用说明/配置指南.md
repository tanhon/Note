# Obsidian 配置指南

## 一、插件安装

### 必需插件

1. **Templater** (社区插件)
   - 用途：支持模板中的动态内容生成
   - 配置要点：
     - 在设置中启用 Templater 插件
     - 设置模板文件夹为 `template`

2. **Obsidian Bases** (社区插件)
   - 用途：支持 BASE 数据库功能
   - 配置要点：
     - 安装后自动识别 `.base` 文件

3. **其他推荐插件**（已在 CLAUDE.md 中列出）

---

## 二、模板插件配置

### 1. 设置模板文件夹

1. 打开 Obsidian 设置
2. 进入"核心插件" -> "模板"
3. 启用模板插件
4. 在"模板文件夹"中选择 `template`

### 2. Templater 插件配置

1. 打开社区插件市场
2. 搜索并安装 "Templater"
3. 启用 Templater 插件
4. 进入 Templater 设置：
   - 设置"用户模板文件夹"为 `template`
   - 启用以下选项：
     - ✅ 在创建时应用模板
     - ✅ 在打开时应用模板
     - ✅ 启用用户脚本

---

## 三、使用模板创建笔记

### 方法一：使用命令面板

1. 按 `Ctrl+P` (Windows) 或 `Cmd+P` (Mac) 打开命令面板
2. 输入 "Templater: Insert template"
3. 选择所需的模板
4. 模板内容会插入到当前光标位置

### 方法二：创建新笔记时自动应用

1. 在目标文件夹（如 Zettelkasten）中创建新笔记
2. 使用 `Ctrl+P` -> "Insert template"
3. 选择对应模板

### 方法三：设置默认模板

对于日记笔记，可以设置每天自动创建：
1. 进入"核心插件" -> "日记"
2. 设置日记文件夹为 `Diary`
3. 设置日记模板为 `Diary模板`
4. 选择日期格式

---

## 四、BASE 数据库使用

### 1. 打开 BASE 数据库

1. 在 Obsidian 侧边栏中找到 BASE 插件
2. 点击打开 `Reference_base.base` 或 `Zettelkasten_base.base`
3. 选择需要的视图（表格视图或卡片视图）

### 2. 自定义视图

可以基于现有视图创建新的视图：
1. 在 BASE 中点击"新建视图"
2. 选择视图类型（表格/卡片/日历等）
3. 配置筛选器、排序和显示字段

### 3. 使用随机排序

对于 Zettelkasten 数据库的卡片视图：
- 随机数会每分钟变化一次（基于当前时间的分钟数）
- 要获得新的随机排列，等待1分钟或刷新视图
- 这种设计帮助发现意想不到的知识连接

## 六、工作流建议

### 1. 日常笔记流程

1. **创建原子笔记**
   - 在 Zettelkasten 文件夹中创建新笔记
   - 使用 Zettelkasten模板
   - 每则笔记只包含一个核心想法

2. **建立链接**
   - 使用 `[[ ]]` 语法链接相关笔记
   - 在上下文中添加链接，不要孤立链接
   - 利用反向链接面板发现新的连接

3. **每日复盘**
   - 在 Diary 文件夹中创建当日笔记
   - 使用 Diary模板
   - 记录新增笔记和学习收获

4. **创作内容**
   - 在 Create 文件夹中使用 Create模板
   - 记录创作进度和发布平台

### 2. 知识管理最佳实践

- **原子化原则**：每则笔记一个想法
- **渐进式总结**：从具体到抽象建立链接
- **定期审查**：每周整理链接，每月复习重要笔记
- **主动连接**：主动寻找笔记之间的联系，不要等待
- **使用标签**：合理使用标签进行分类

## 七、常见问题

### Q1: 模板内容没有自动填充？

**解决方案**：
1. 确保 Templater 插件已启用
2. 检查模板文件夹设置是否正确
3. 确保在创建笔记后手动插入模板（或配置自动插入）

### Q2: BASE 数据库不显示笔记？

**解决方案**：
1. 确保笔记保存在正确的文件夹中（Reference 或 Zettelkasten）
2. 检查 BASE 插件是否已启用
3. 刷新 BASE 视图

### Q3: 如何修改随机排序公式？

**解决方案**：
1. 打开 `BASE/Zettelkasten_base.base`
2. 找到 "随时间变化的随机数" 字段
3. 修改 formula 属性中的公式
4. 保存后刷新 BASE 视图

### Q4: 如何添加新的模板？

**解决方案**：
1. 在 `template/` 文件夹中创建新的 `.md` 文件
2. 使用 YAML frontmatter 定义元数据
3. 在文件内容中使用 Templater 语法
4. 保存后即可在命令面板中使用

### Q5: 如何备份知识库？

**解决方案**：
推荐使用以下方法：
1. **Git 版本控制**：初始化 git 仓库并定期提交
2. **云同步**：使用 Obsidian Sync 或其他云服务
3. **本地备份**：定期复制到外部存储
