## 阶段二：首次使用 (预计时间: 10分钟)

### 2.1 创建第一个原子笔记

- [x] 在 `Zettelkasten/` 文件夹中创建新笔记 ✅ 2026-03-02
- [x] 命名为有意义的主题（如"知识管理的核心原则"） ✅ 2026-03-02
- [x] 插入 `Zettelkasten模板` ✅ 2026-03-02
- [x] 观察 Frontmatter 是否自动填充 ✅ 2026-03-02
- [x] 在内容区域写下核心想法 ✅ 2026-03-02
- [x] 保存笔记 ✅ 2026-03-02

### 2.2 创建今日日记

- [ ] 在 `Diary/` 文件夹中创建笔记
- [ ] 使用今天的日期命名（如 `2026-02-25`）
- [ ] 插入 `Diary模板`
- [ ] 填写"今日计划"部分
- [ ] 在"新增笔记列表"中记录刚才创建的原子笔记
- [ ] 填写简单的反思
- [ ] 保存笔记

### 2.3 测试链接功能

- [ ] 在刚才创建的原子笔记中，输入 `[[`
- [ ] 确认能看到笔记建议列表
- [ ] 选择今日的日记笔记，创建链接
- [ ] 保存后，点击链接测试是否能跳转
- [ ] 在日记中也链接回原子笔记

## 阶段三：数据库探索 (预计时间: 10分钟)

### 3.1 浏览 Reference_base.base

- [ ] 在 Obsidian 侧边栏找到 BASE 插件
- [ ] 点击打开 `Reference_base.base`
- [ ] 观察表格视图的布局
- [ ] 检查是否有任何笔记显示（初始应该是空的）
- [ ] 查看列标题：文件名、创建时间、修改时间、AI摘要

### 3.2 浏览 Zettelkasten_base.base

- [ ] 打开 `Zettelkasten_base.base`
- [ ] 查看"表格视图"
  - [ ] 观察笔记是否按创建时间排序
  - [ ] 检查显示的字段
- [ ] 切换到"卡片视图"
  - [ ] 观察卡片布局
  - [ ] 注意卡片的随机排序
- [ ] 等待1分钟后刷新，观察卡片顺序是否变化

### 3.3 添加测试笔记

- [ ] 在 `Zettelkasten/` 中创建2-3个测试笔记
- [ ] 返回 `Zettelkasten_base.base`
- [ ] 在表格视图中确认新笔记出现
- [ ] 在卡片视图中查看新笔记的显示
