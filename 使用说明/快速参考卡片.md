# 🚀 快速参考卡片

## 📁 文件夹用途速查

| 文件夹 | 用途 | 模板 |
|--------|------|------|
| `Zettelkasten/` | 原子化笔记 | Zettelkasten模板 |

## 📝 模板快速使用

### 1. 创建原子笔记

```
位置: Zettelkasten/新笔记名
模板: Zettelkasten模板

Frontmatter 自动包含:
- created (时间戳)
- random_id (随机标识符)
- 时间戳UID (唯一ID)
- 页面ID (组合格式)
```

### 2. 创建创作内容

```
位置: Create/作品名
模板: Create模板

Frontmatter 包含:
- Status: 创作中
- platform: []
- tags: []
- AREA:
- category:
```

### 3. 创建每日笔记

```
位置: Diary/2026-02-25
模板: Diary模板

包含结构:
- 日期记录
- 今日计划
- 新增笔记列表
- 当日笔记分析
```

## 🔗 链接语法速查

| 语法 | 说明 | 示例 |
|------|------|------|
| `[[笔记名]]` | 内部链接 | `[[知识管理]]` |
| `[[笔记名\|显示文本]]` | 自定义显示 | `[[知识管理\|了解更多]]` |
| `[[笔记名#标题]]` | 链接到标题 | `[[笔记#概述]]` |
| `[[笔记名#^块标识]]` | 链接到块 | `[[笔记#^123456]]` |
| `![[文件]]` | 嵌入内容 | `![[图片.png]]` |
| `[[^^搜索文本]]` | 搜索并链接块 | `[[^^重要概念]]` |
| `[[##标题]]` | 搜索并链接标题 | `[[##结论]]` |

## 🗂️ BASE 数据库使用

### Reference_base.base

```
目标: Reference/ 文件夹
视图: 表格视图
排序: 创建时间降序
字段: 文件名、创建时间、修改时间、AI摘要
用途: 管理参考资料，快速查找最新内容
```

### Zettelkasten_base.base

```
目标: Zettelkasten/ 文件夹
视图1: 表格视图 (按时间排序)
视图2: 卡片视图 (随机排序)
特殊功能: 随时间变化的随机数
用途: 浏览知识卡片，发现意外连接
```

**随机排序公式**:
```
(( (number(this.时间戳UID) * 100011979 + 500067713) % 900066731 )
 * ( (now().minute * 800067089 + 800068411) % 800053967 )
 + 900067309) % 900066571
```

## 🎯 核心工作流

### 🌱 每日流程 (5分钟)

1. 打开 Obsidian
2. `Ctrl+O` 打开或创建今天的日记
3. 记录今天的计划和想法
4. 创建至少一个原子笔记
5. 为新笔记建立链接

### 🔄 每周流程 (30分钟)

1. 回顾本周创建的笔记
2. 完善笔记之间的链接
3. 整理新增的参考资料
4. 审查反向链接，发现新连接
5. 更新创作内容的进度

### 📊 每月流程 (1小时)

1. 回顾重要笔记，加深理解
2. 优化知识结构，删除冗余
3. 检查模板是否需要调整
4. 备份整个知识库
5. 设定下月学习目标

## 💡 最佳实践

### ✅ 应该做的

- ✅ 每则笔记一个核心想法
- ✅ 使用描述性标题
- ✅ 主动建立笔记链接
- ✅ 定期复习和整理
- ✅ 使用标签进行分类
- ✅ 保持笔记简洁明了

### ❌ 避免做的

- ❌ 单个笔记包含多个主题
- ❌ 创建孤立的笔记（没有链接）
- ❌ 忽略定期复习
- ❌ 过度分类和标签
- ❌ 完美主义（先完成再完美）

## 🔍 搜索命令

在终端中使用：

```bash
# 搜索文件名
fd "关键词"

# 搜索文件内容
rg "关键词"

# 搜索 Markdown 文件
fd -e md "关键词"

# 不区分大小写搜索
rg -i "关键词" --type md

# 搜索包含特定 frontmatter 的文件
rg "created:" --type md
```

## 🆘 常见问题

**Q: 模板没有自动填充？**
A: 确保 Templater 插件已启用并正确配置

**Q: BASE 不显示笔记？**
A: 检查笔记是否在正确的文件夹中（Reference 或 Zettelkasten）

**Q: 如何修改模板？**
A: 编辑 `template/` 文件夹中的对应文件

**Q: 如何备份？**
A: 使用 Git 或复制到云存储/外部硬盘
