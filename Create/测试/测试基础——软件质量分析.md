# 衡量一个软件质量的维度

1. 功能性：功能数量正确，不多不少；功能正确实现。
2. 性能：响应快，资源占用少，主要是高并发处理。
3. 兼容性：不同平台或设备可以正常使用。
4. 易用性：易学、易用、用户体验好。
5. 安全性：加密传输，存储有保障。
6. 可靠性：持久运行无重大异常。
7. 可移植性：应用系统升级，数据迁移方便。
8. 可维护性：出现异常时，易修复。
