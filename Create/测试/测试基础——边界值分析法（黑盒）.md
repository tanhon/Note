# 边界值分析法
##### What？
一种对输入或输出的边界值进行测试的方法。
##### Why？
等价类划分忽略掉了某些特定类型的高效测试用例，而边界值分析可以弥补其中的很多不足。
边界值分析法也是对等价类划分法的一个补充。
##### How？
选取分三种：
1. 上点：正好是边界处的点，必须选择。
2. 离点：距离上点最近的点，选择两个，上点左侧和右侧各一个。
3. 内点：边界范围内的任意点，一般选中间常见的，必须选择。
##### 与等价类划分法的关系
等价类划分了测试范围，分成多个区域，而边界值分析了每个区域的连接处，寻找最可能出现 BUG 的极值点。
##### 等价类例子的补充
需求：假设一个网站的注册密码有这样的需求，长度8-16位，必须包含字母和数字。

| 输入条件 | 有效等价类 | 编码  | 无效等价类 | 编码  |
| ---- | ----- | --- | ----- | --- |
| 边界值点 | 8 位   | 11  | 7 位   | 13  |
|      | 16 位  | 12  | 9 位   | 14  |
|      |       |     | 15 位  | 15  |
|      |       |     | 17 位  | 16  |



| 测试用例编号 | 输入数据              | 预期输出   | 覆盖等价类（编码） |
| ------ | ----------------- | ------ | --------- |
| 11     | abcd1234          | 有效     | 1、2       |
| 12     | abcdef0123456789  | 有效     | 1、2       |
| 13     | abcd123           | 长度不足   | 2、3       |
| 14     | abcd12345         | 有效     | 1、2       |
| 15     | abcdf123456789    | 有效     | 1、2       |
| 16     | abcdefg0123456789 | 超出长度限制 | 2、4       |
