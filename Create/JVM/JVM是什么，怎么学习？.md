Java Virtual Machine ，Java 程序的**运行环境**（Java 二进制字节码的运行环境）。
## JVM 核心可以拆成 **4 条主线**：
### 1. 内存结构（最基础）

- 堆（Heap）
- 方法区（MetaSpace）
- 虚拟机栈
- 程序计数器
- 本地方法栈

本质问题：  
**“Java 对象到底存在哪里？方法怎么执行？”**

---

### 2. 类加载机制（执行前）

- 类加载过程：加载 → 验证 → 准备 → 解析 → 初始化
- 双亲委派模型
- 自定义类加载器

本质问题：  
**“类是怎么进 JVM 的？”**

---

### 3. 执行引擎（运行时）

- 字节码执行
- 解释器 vs JIT 编译器

本质问题：  
**“代码是怎么跑起来的？”**

---

### 4. 垃圾回收（GC）

- 如何判断对象是否存活
- GC 算法（标记清除 / 复制 / 标记整理）
- 分代收集
- 常见 GC（G 1 / CMS）

本质问题：  
**“内存满了怎么办？”**
