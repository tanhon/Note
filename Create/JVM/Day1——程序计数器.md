### 【模块名称】

JVM 的内存结构——程序计数器
### 一、核心问题
这个知识点解决什么问题：

CPU 是怎么一步一步读取指令的？
### 二、结论
用 3~5 句话讲清本质

程序计数器会记录下一条 jvm 指令的  指令执行地址行号，
然后由解释器对 jvm 指令翻译成机器码，
最后机器码传给 CPU 来执行指令
### 三、关键机制 / 原理

特点：
1. 每个线程都有自己的程序计数器，在切换线程时，程序计数器都会记录当前线程下一条指令的地址，以便线程恢复执行后不会从头开始执行。
2. 不存在内存溢出的情况

### 四、图示
（用文字/工具）
jvm 指令 -> 程序计数器 -> 解释器 -> 机器码 -> CPU
