### 三种开闭区间写法主要不同的地方：
1. 左右边界缩小时，left、right该 +1 还是 -1
2. while 循环的终止条件——什么时候不需要再查找了——区间为空
		左闭右闭——left <= right
		左闭右开——left < right
		左开右开——left + 1 < right

### 核心代码：

```cpp
int left = 0, right = nums.size();
while(left < right){
	int mid = left + (right - left) >> 1;
	if(nums[mid] < target){
		left = mid + 1;
	} 
	else{
		right = mid;
	}
}

return left;
```

### 计算中间索引的安全且高效的方式
left + ((right - left) >> 1)  
= left + ((right - left) / 2)  
= (2 left + right - left) / 2  
= (left + right) / 2

为什么这样写？
答：
1、避免整数溢出，如果 left 和 right 的值非常大，当它们想加时就可能超出 int 的最大值 21 亿。
2、使用位运算就是为了加快计算速度，位运算通常比除法运算更快。
