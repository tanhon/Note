二进制下的表现：

| 运算  | 符号   | 含义      |
| --- | ---- | ------- |
| 与   | `&`  | 同时为1才为1 |
| 或   | `\|` | 有1就为1   |
| 非   | `~`  | 0变1，1变0 |

集合角度理解：
& → 保留共同的 1（交集）
| → 合并所有的 1（并集）
~ → 取反所有位（补集）

应用：
// 判断奇偶
x & 1 —— 奇数
0000 0000，我们知道，第 n 位代表数值 $2^{n-1}$ ，而 1 的二进制又是 0000 0001，这里的 1 就是 $2^0$
前面的都是 2 的倍数，所以都是偶数，最后加上这个 1 就变成奇数了。

// 判断第 k 位
<font color="#00b050">x & (1 << k) </font>
<font color="#00b0f0">本质：只保留第 k 位，其它位全部清零。</font>
因为第 k 位是 1，&代表交集，所以只有第 k 位的 1 被保留下来了，其他都被清零。

// 设置第 k 位
<font color="#00b050">x | (1 << k)</font>
<font color="#00b0f0">本质：第 k 位无论原来是 0 还是 1 → 结果一定是 1</font>

// 清除第 k 位
<font color="#00b050">x & ~(1 << k)</font>
<font color="#00b0f0">本质：把第 k 位强制变成 0，其它位不变</font>

理解 1<< k：第 k 位是 1，其余都是 0
1 << 0 → 0001
1 << 1 → 0010
1 << 2 → 0100
1 << 3 → 1000

理解~(1 << k)：第 k 位是 0，其余全是 1
1 << 1 = 0010
~(1<<1) = 1101


### 补充——异或 a ^ b
在集合中，异或运算（也称为对称差）用于表示属于一个集合但不同时属于另一个集合的元素。（韦恩图中的"月牙"）
